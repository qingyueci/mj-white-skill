# MJ WHITE｜海报展示

本套六页宣传海报介绍 MJ WHITE 从画面概念到可复用方法的流程：留白、色域、人物动作、东方巨构、构图机制与提示词编译。

## 三种版本

- [文字排版版](posters/)：1080 × 1920，HTML 源文件可编辑，中文由版面排字。
- [Image 材质底版](posters-image/)：1080 × 1920，由 Image 生成矿物纸感材质，文字保留排版源文件。
- [Image 全画面艺术版](posters-image-art/)：941 × 1672，Image 重新创作版式、字体和图像，适合艺术方向展示；第 05 页左上和第 06 页底部品牌字样统一为 `MJ WHITE`。

全画面艺术版视觉复核通过，01–06 可作为社媒轮播候选；建议发布单页原图。小号装饰字、印章和细边注可能存在生成式字形偏差或移动端难读的问题，需人工校对，不承载核心信息。
