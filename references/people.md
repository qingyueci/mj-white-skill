# 人物场景｜动作中间态

人物可以是近景、中景或远景，不能把某一张案例的景别当作默认值。先选观看位置与几何：偏心框景、斜向纵深、前景遮挡、倒影、光影、曲面布料等；避免连续使用人物居中＋水平地平线。

- **动作闭环**：目光落点 → 稳定物件的手／支撑 → 施力的手 → 接触与运动路径 → 可见结果。只描述画面确实需要的手部职责；裁切镜位下不强求双手都入画。
- **物理反馈**：发丝、衣袖、树叶、烟、水纹与布料服从同一风向、重力和光源。情绪来自刚发生或将发生的动作，不以无因果的奇观代替。
- **近景**：脸与关键接触点可读，建筑的檐、柱、窗、栏等后景仍能辨识；不要让空墙或过浅景深抹去地点。真人质感不等于统一白衣或暗光。
- **器物与手**：写清相对于身体的位置、承托面、左右手职责和施力方向；避免漂浮器物、断开的手臂或袖口。水中倒影应与实物位置、视角、光线和波纹一致。
- **色域**：先指定墙、水、花树、衣物、帘幕等主色载体，再指定小面积对位色和光源色。保留黑位与高光；不要为了“中式”自动加入灰雾或旧纸滤镜。
